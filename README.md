# Quix Website

Public landing page for **Quix**, a free Minecraft Java Edition launcher currently in planning and design.

This repository contains the static website only. The launcher project lives at [QuixLauncher/quix-launcher](https://github.com/QuixLauncher/quix-launcher).

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select **main**, folder **/(root)** and click **Save**.
4. Once published, the site should be available at https://quixlauncher.github.io/QuixLauncher-Website/.

No build tools, dependencies, API keys, or server are required.

## Files

- `index.html` — landing page, responsive layout and illustrative UI concept.
- `favicon.svg` — **temporary vector approximation** of the Quix icon. Replace this with the approved official icon file before final branding.

## Status

The visualized app is a **concept**, not a screenshot of a working launcher. Quix has no public download at this stage. Modrinth and CurseForge integration is planned and subject to the relevant API rules and permissions.
