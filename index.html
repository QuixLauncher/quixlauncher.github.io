Unveiling the Experience

Built like a modern tool.
Not an advertisement board.

The desktop experience is designed around three focused spaces: an isolated library for your worlds, a clean discovery hub for community content, and an intuitive system panel.

01 // THE LIBRARY

Every world in its own sandbox

Keep your vanilla survival, tech modpacks, and speedrun setups completely separate. Isolated instance directories help protect against mod conflicts, separate your options, and preserve your custom keybinds.

Instance Isolation Dedicated Sandboxes
02 // DISCOVERY

Instance Management

Your game.
Organized with precision.

Mods can be added directly into your existing compatible instances.
Modpacks are complete installations and automatically generate new independent instances with their required loaders and runtime settings.

System & Reliability

Everything under control.
Without the complexity.

Quix handles the technical overhead in the background so you can spend less time configuring directories and more time in your worlds.

Smart Java Selection

Designed to automatically detect and suggest compatible OpenJDK builds for your instance loader (Java 8, 17, or 21), minimizing manual environment variable editing.

✦ Planned automated runtime manager

Custom Instance Settings

Configure dedicated window resolutions, allocated memory thresholds, and separate game directories for each profile independently.

✦ Planned per-instance controls

Safe Updates & Local Backups

Manage updates with clear choices instead of unexpected overwrite prompts. Local snapshot backups help safeguard your configurations before testing experimental mods.

Project Status

Planned with care.
