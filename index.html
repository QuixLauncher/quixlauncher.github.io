The Philosophy

Why start from scratch?
Because modding shouldn't feel like file archaeology.

01 / The Status Quo

The Shared Folder Trap

Every veteran Minecraft player knows the frustration: installing one modpack accidentally overwrites keybindings in another. Forge and Fabric fight over the same `.minecraft` folder, crash logs provide zero useful context, and popular launchers have become bloated with video ads and sponsored widgets.

  • Config files silently corrupted across versions
  • Manual Java version path juggling for old vs new packs
  • Laggy web-wrapper interfaces loaded with intrusive ads
  • Three different websites open just to assemble one shader pack
02 / The Quix Foundation

Strict Instance Sandboxing

Quix treats every setup as an isolated, self-contained container. A 1.20.1 Forge factory world and a 1.21.1 Fabric speedrun profile live in completely separate directories. Nothing leaks, nothing collides, and closing the launcher frees every byte of system RAM.

  • Every world, mod, and shader lives in its own sandboxed vault
  • Unified discovery: search Modrinth & CurseForge from one screen
  • Automatic OpenJDK runtime provisioning (Java 8, 17, 21)
  • 100% free, independent, and zero promotional noise
Planned Capabilities

Built for speed.
Obsessed with the details.

We are engineering Quix around four non-negotiable principles: isolation, unified discovery, automated runtimes, and zero bloat.

Isolated Instance Sandbox

Every instance is an independent container with its own isolated `mods/`, `saves/`, `shaderpacks/`, and `options.txt`. Test an experimental shader or upgrade a mod without risking your main 300-hour survival world.

Path: /quix/instances/{instance-id}/ Zero Cross-Pollution

Dual-Ecosystem Search

Find content across Modrinth and CurseForge in a single query. Quix resolves dependencies automatically so you never get a "missing library" screen on startup.

Modrinth v2 + CurseForge APIs

Automated Java Orchestration

Never configure `JAVA_HOME` environment variables again. Quix downloads and pairs the exact compatible OpenJDK build (8, 17, or 21) needed for your specific loader.

Eclipse Temurin / GraalVM Auto-Provisioned

Visual Shader Management

Hot-swap shader packs, tweak shadow resolutions, and toggle LabPBR materials with live preset previews before entering your world.

Iris & Oculus Compatible

Snapshot Vault & Instant Rollback

Updating a modpack with 100 mods should not be a gamble. Quix creates atomic snapshots before any batch update. If a new version crashes, restore the exact working state in one click.

Rollback Protocol: `quix snapshot restore` Crash Proof
