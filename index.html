Why Quix Exists

Say goodbye to setup fatigue.

Minecraft Java is one of the greatest creative sandboxes in gaming history. But managing versions, loaders, broken shader directories, and scattered mod files shouldn't feel like a chore.

01 / ISOLATION

No More File Collision

Traditional setups dump all worlds, mods, and configs into a single shared folder, leading to subtle config corruption and game crashes. Quix encapsulates every single profile into its own strict sandbox.

✦ True folder isolation per instance
02 / INTEGRATION

Curated Dual Discovery

Stop jumping between dozens of browser tabs and suspicious download mirrors. Quix is designed to connect directly with both the Modrinth and CurseForge APIs, allowing one-click mod and shader installation.

✦ Modrinth & CurseForge combined
03 / RESPECT

Zero Bloatware or Ads

You shouldn't have to dodge video pop-ups, telemetry tracking, or cryptocurrency rewards just to launch your game. Quix is built as an independent, distraction-free product for true enthusiasts.

✦ Pure launcher, zero corporate clutter
Planned Capabilities

Precision engineering.
Down to the byte.

Every feature in Quix is being architected with an obsession for speed, clean UX, and complete user autonomy.

Strict Instance Sandboxing

Run Minecraft 1.7.10 with OptiFine alongside 1.21.4 NeoForge with Iris without cross-contamination. Each instance maintains its own dedicated `options.txt`, keybindings, shaderpacks, and save directories.

Instance Container: /quix/instances/survival-2026/ Zero Leakage

Dual Ecosystem Discovery

Access millions of mods and shaderpacks from both Modrinth and CurseForge inside a unified search architecture with automatic dependency resolution.

APIs: Modrinth v2 + CurseForge Unified Feed

Automated Java Orchestration

Never wrestle with `JAVA_HOME` variables again. Quix will automatically fetch, sandbox, and bind the exact Java runtime (Java 8, 17, or 21) required by your loader.

Eclipse Temurin / GraalVM Auto-Pinned

Visual Shader Management

Preview and switch shader profiles (Iris, Oculus, OptiFine) with live config toggles. Enable or disable labPBR textures and shadow maps without restarting the game.

Iris & Oculus Pipeline Hot Swappable

Snapshot Vault & Rollback Protection

Updating 50 mods at once shouldn't break your 200-hour world. Quix creates atomic pre-update snapshots, giving you a painless one-click rollback if an updated mod introduces fatal incompatibilities.

Instant Rollback: `quix snapshot restore` Safe Updates
